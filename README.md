# UMINIKTA - Next-Generation Academic Portal

Official collaborative academic learning platform of the **University of Mindanao**, developed within the **College of Computing Education (CCE)**.

## Quick Start & Local Setup

For complete step-by-step setup, configuration, and troubleshooting instructions, see:



### Quick Commands

```bash
# 1. Install dependencies
npm install

# 2. Configure .env with Supabase credentials
# EXPO_PUBLIC_SUPABASE_URL=...
# EXPO_PUBLIC_SUPABASE_ANON_KEY=...

# 3. Start local development server
npm start
# or run directly in browser
npm run web
```

## Features & Highlights

- **Virtual Classrooms**: Real-time course streams, announcements, lecture files, and interactive student Q&A.
- **Role-Tailored Portals**: Purpose-built interfaces for **Students** (Emerald), **Professors** (Royal Indigo), and **SecOps** (Cyber Obsidian).
- **007 Hardened WAF Perimeter**: Automated rate limiting, proxy/VPN detection, and threat inspection.
- **Offline-First Resilience**: Local database mutation queueing with automatic background synchronization upon reconnection.
- **Data Privacy Act (RA 10173)**: Full statutory compliance, transparent governance, and dedicated DPO contact integration.
